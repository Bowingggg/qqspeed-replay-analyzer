# QQ飞车录像分析器

把 QQ飞车 `.sav` 录像解析成可核对的分析链：地图身份 → 物理 telemetry → 原生漂移/小喷/动作 → 官方地图几何 → 驾驶分段与 A/B 对比。

本项目是本地运行的单机工具：程序只读取你自己的录像和游戏安装目录，不联网、不上传、不需要数据库。

---

## 功能

- **`.sav` 录像解析** — 读取 QQ飞车录像，还原每圈的实际行驶轨迹与速度。
- **原生 telemetry** — 速度与位置取自 replay-native 的物理车辆流；物理流与逻辑影子分别发布。
- **原生 Drift / action** — 漂移按 replay-native 的 action-object Drift 表切分；空喷、落地喷、CW / WCW / CWW 取自 replay-native action event table。几何只做测量，不反向定义动作语义。
- **官方地图路线** — 地图身份以游戏资源自带的声明 MapID 为主权威；路线几何来自官方 `map.nif`，不做轨迹拟合。
- **单录像路线查看** — 在地图上查看某一圈的实际行驶路线、漂移分段与本地指标。
- **不同录像 A/B 对比** — 同一张官方地图的两张录像逐段对比。
- **同一录像不同圈 A/B 对比** — 直接比较同一个 `.sav` 的两个不同圈次。
- **圈1 vs 圈2 / 圈1 vs 圈3 / 圈2 vs 圈3** — 任意两个真实存在的圈都可以配对比较；同录像两侧圈次独立选择，且不允许同一圈与自身比较。
- **分段指标** — 每个分段发布核心时间、入弯速度、最低弯速、出弯速度、漂移距离、出弯→恢复距离、总距离，每项都带定义与权威来源标注。
- **速度 / 距离 / 时间比较** — 同一步段两侧并排显示，差值精确取反（交换 A/B 后区间不变）。

## 快速开始

1. 双击项目根目录的 **`启动前端.bat`**。
2. 程序在本地启动前端服务并自动打开浏览器（默认 `http://127.0.0.1:17853`，端口被占用时自动顺延）。
3. 在 **设置** 里选择 QQ飞车 游戏安装目录。
4. 等待后台完成 **游戏资料首次初始化**（官方地图目录 + `GameMapID ↔ ResourceMapID` 绑定）；初始化完成前 **添加录像** 保持禁用。
5. 点 **添加录像** 选择一个或多个 `.sav`，分析自动开始。

初始化只需做一次，之后每次启动都是空操作。官方资料就绪后不需要任何手工命令。

**系统要求**：Windows 10/11 + Windows PowerShell 5.1 + .NET Framework（均为系统自带）+ 已安装 QQ飞车客户端。不需要 Node.js、Python 或任何第三方运行时。

## A/B 对比

### 不同录像之间

选择另一张同图录像作为 B 侧。两侧默认使用相同的圈号；地图身份不一致时对比会被拒绝。

### 同一录像不同圈之间

B 侧选择 **本录像 · 圈间比较**，然后分别选择 A 圈与 B 圈：

- A / B 圈次**独立选择**，切换 A 圈不会强行把 B 圈拖到同一圈。
- 如果 A 落到 B 当前圈，B 会自动切换到另一个真实存在的圈。
- **不允许同一圈与自身比较**；只有一圈的录像不提供本录像圈间比较入口。
- 圈次来自录像原生的圈表，不引入任何几何猜测。

### 对比数字的语义

- A / 当前 永远是蓝色，B / 参考 永远是橙色。
- 主时间差用文字表达：**快 / 慢 / 持平**，不用带正负号的数字；只有精确相等才是「持平」。
- 配对弯道分三层报告：**核心弯道**（较早的起漂 → 较早的自然恢复结束）、**恢复收益/损失**、**最终净结果**（同一起点 → 较晚的自然恢复结束）。较长的单喷/双喷尾巴不会放大核心窗口。
- 出弯速度与恢复距离是各侧在**自己**的语义窗口内的测量，不受共享空间边界裁剪。
- 地图身份无法权威解析时对比会被拒绝，不做猜测性对齐。

**路线模式**（地图上方的模式按钮）：

- `all` — 显示全部路线，只看路线形状。
- `drift` — 只按原生漂移本体切段。
- `recovery`（默认）— 从 **起漂** 到 **原生恢复结束**。恢复终点只认 `code2001` 普通小喷；氮气、地图推进力、未知效果都不会延长分段；遇到持续腾空（`contact_state == 0` 且 ≥100ms）会在起飞处硬切断。
- `custom` — 在 A 侧地图上自定义起点/终点区间，程序把它映射到同一个世界坐标区间再比较。

## 指标与数据可信度

程序刻意区分三类数字：

- **结算口径（primary）** — 已与游戏结算闭合的量：空喷、落地喷、CW / WCW / CWW、逻辑漂移次数。
- **仅原生证据（raw only）** — 普通小喷（`code2001`）与氮气（`code1`）。只发布原生区间数并标注 parity 为 `unresolved`，**不发布**对应的游戏结算数字，也不把原生区间改名为结算标签。
- **不可用（unavailable）** — 证据不足时明确显示为不可用（—），绝不填 0 冒充。

原则是：能确认的才展示，未确认的明确标注 unavailable / unresolved，不用猜测填空。

## 已知限制

- **普通小喷（`code2001`）与氮气（`code1`）的结算口径尚未闭合。** 已知金标录像里 `code2001` 原生区间比游戏结算多 7 次、氮气多 1 次；未找到可重放的原生机制，因此不做规则推断。
- **部分录像变体无法对齐。** 少数录制场次的 action event 表与 `code2001` 区间完全对不上（常数时基偏移也无法恢复）。这类录像判为 replay variant：只发布原生证据，扣发 game-facing 计数。
- **动态场景几何未解析。** 官方 `map.nif` 的移动/动画场景物件驱动仍未解开；`code2003` 已被确认为地图推进力效果，与场景几何无关。
- **地图身份存在少数未决项。** 资源目录可能声明冲突的游戏 MapID；冲突时保持 unresolved（fail closed），不用偏移量猜。
- **前端是单请求串行处理。** 一次长分析进行时，其它界面请求会短暂等待；单用户本地使用可接受。
- **仅支持 Windows**，依赖 Windows PowerShell 5.1 与 .NET Framework。
- 分析速度取决于录像大小与是否命中缓存；首次分析需要完整扫描录像尾部。

## 隐私

- 程序**不联网**：不发送、不上传任何数据，没有遥测、没有账号、没有云同步。
- 程序**只读取**你指定的 `.sav` 录像和 QQ飞车安装目录中的资源文件。
- 分析结果与缓存全部写在本地项目目录内。
- 录像文件名通常包含玩家昵称。这些文件只留在你本机 `Data\ReplayArchive\`，**不会被提交到版本库**（见 `.gitignore`）。
- 仓库与发行包中不含真实录像、个人配置、邮箱、令牌或机器相关的绝对路径。

## 从源码验证

程序自带验证门禁，可在解压后的根目录直接运行：

```powershell
# Fast Gate — 日常默认，不需要真实录像，约 1–2 分钟
powershell -NoProfile -ExecutionPolicy Bypass -File "Data\App\Tests\Smoke-Fast.ps1"
```

标记为 Real Regression 的测试需要真实录像语料（放在 `Data\ReplayArchive\`）。**全新安装没有这些录像时它们会被跳过，这是预期行为**，Fast Gate 不受影响。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File "Data\App\Tests\Smoke-RealRegression.ps1"
powershell -NoProfile -ExecutionPolicy Bypass -File "Data\App\Tests\Smoke-Full.ps1"
```

`Data\App\docs\ARCHITECTURE.md` 描述当前的权威（authority）边界；`Data\App\docs\decisions\` 记录重大设计决策的来龙去脉。
